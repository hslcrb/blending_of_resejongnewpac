# 후속 외관 형상 보정: 사진 092·095의 회랑

## 대조에서 확인한 차이

원본 파일 `20261101답사/KakaoTalk_20261102_024845377_01.webp`(092), `..._04.webp`(095)를 확대해 확인했다. 두 사진에서 회랑 기둥은 넓게 꺾인 어깨와 연속된 석재 줄눈이 보인다. 기존 모델은 폭 약1.44m×깊이1.93m의 외곽에 모따기0.12m인 8각단면이라 렌더에서는 거의 직사각 기둥처럼 보였다.

사진의 회랑 천장은 밝은 은색이 아닌 짙은 회색 패널이다. 기존 재질의 선형 RGB 0.245는 야간 직접 조명 아래에서 지나치게 밝았다.

## 실제 변경

1. **기둥 7개의 어깨 단면**: 모따기를0.12m에서0.38m로 시각 보정했다. 기존 중심, 외곽 폭·깊이, 높이, 기둥 간격은 바꾸지 않았다. 0.38m는 사진 비교값이지 현장 실측값이 아니다. 원형 기둥이라고 단정하거나 임의 원통으로 바꾸지 않았다.
2. **석재 수평 줄눈·하부 마감**: 기둥 어깨와 함께 이동해 기존 얇은 줄눈이 바깥으로 떠 있지 않도록 했다. 평면에 있는 세로 줄눈은 변경하지 않았다.
3. **회랑 천장 패널**: 기존 패널·홈·점검구 형상은 유지하고 선형RGB를 패널(0.055,0.060,0.055), 홈(0.025,0.027,0.025), 점검구테두리(0.18,0.19,0.18)로 조정했다. 이 색은 조명 아래 시각 보정이며 측색값이 아니다.

## 손상 방지

- 큰 통합 `stone` 메쉬에서 **독립된16정점 기둥 성분7개**만 선택한다. `assert len(eligible)==112` 및 실제변경112정점 assertion으로 주변 벽·바닥이 섞이지 않는지 검증한다.
- 기존20261105 원본과 첫20261115 주야간 파일은 그대로 보존한다. 새 `.blend`: `blender_work/20261115-survey/sejong_survey_colonnade_refined.blend`.
- 수정객체4개만 634,592 bytes GLB로 내보낸다. 나머지 캠퍼스·실내·나무를 재생성하지 않는다.
- `colonnade-day.png`/`colonnade-night.png`와 `colonnade-day-refined.png`/`colonnade-night-refined.png`는 동일 카메라·조명 설정의 실제 Blender 전후 렌더다.

## 재현

```bash
blender -b blender_work/20261115-survey/sejong_survey_day_night.blend --python scripts/refine_colonnade_geometry_20261115.py
```
