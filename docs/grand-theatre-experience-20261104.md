# 대극장 내부 체험 — 2026-11-04

## 사용

외부 건축 산책의 **대극장 내부 입장**을 누르면 독립적인 내부 장면이 열린다. 첫 위치는 1층 로비이며 마우스나 터치로 시선을 돌리고 W·A·S·D, 방향키 또는 화면의 이동 버튼으로 걸을 수 있다. 로비, 객석 입구, 무대, 무대 뒤편 버튼은 해당 위치로 바로 이동한다. 1층 통로에는 로비와 객석 사이 높이차를 잇는 경사로가 있다.

좌석을 화면에서 누르거나 목록에서 선택하면 해당 좌석의 눈높이로 앉는다. 일어서면 그 층의 가까운 통로로 이동하고 2·3층에서도 지정된 객석 범위를 걸을 수 있다. 층 사이와 무대 주변은 공간 이동 버튼으로 이동한다. 장면에서 공연막, 열린 무대, 음향 반사판과 영상 스크린을 선택할 수 있다.

영상 재생 버튼은 사용자 동작으로 스크린 영사와 공간 음향을 시작한다. Web Audio의 HRTF 위치 음원은 스크린 중심에 위치하며, 헤드폰을 사용할 때 공간감이 더 잘 느껴질 수 있다. 음량·재생 위치를 조절하고 영상 음량에 반응하는 무대효과를 켜거나 끌 수 있다. 영상과 오디오가 준비되지 않거나 재생에 실패하면 상태를 보여준다. 종료 시 영상, 오디오, WebGL 자원을 정리한다.

## 원본과 해석

제공된 1층 약도 및 로비·객석·무대 사진의 색과 구조를 참고해 표현했다. 추정 좌석 수 1,368석과 크기·배치, 특히 사진에서 보이지 않는 무대 뒤편은 실제 실측이나 공식 안내도가 아닌 체험용 재구성이다. 3D 모델의 좌석·무대 좌표 계약과 생성 및 검증은 [grand-theatre-model-20261104.md](grand-theatre-model-20261104.md)에 정리했다.

제공받은 1080p 원본은 `source_media/`에 보존하고, Cloudflare Pages의 단일 파일 용량에 맞춘 전체 길이 720p 사본을 `public/media/`에서 재생한다. 변환과 공간 음향의 자세한 내용은 [theatre-projection-audio-20261104.md](theatre-projection-audio-20261104.md)를 참고한다. 사용자가 제공한 영상의 권리나 공개 이용 허가 여부는 이 프로젝트에서 별도 확인하지 않았다.

## Blender와 하늘

[open-grand-theatre.cmd](../open-grand-theatre.cmd)를 실행하면 `blender_work/20261104-live-sky/grand-theatre/sejong_grand_theatre_20261104.blend` 사본이 열리고 서울 시각·관측 하늘 타이머가 시작된다. 원본은 보존한다. 외부 웹 장면은 낮과 밤의 밝기를 각각 조정하고 날짜에 따른 달의 근사 위치·위상과 절차적 별을 표시한다. 별은 실제 별자리 관측이 아니다. 구름은 김포공항 METAR 분류를 이용한 근사이며 광화문 현장 영상이 아니다. [낮밤 조명 검증](20261104-day-night-lighting.md)과 [Blender 하늘 설명](blender-weather-sky-20261104.md)에 방법과 한계를 기록했다.

## 검증

`node --test tests/theatre-navigation.test.js tests/theatre-lobby.test.js tests/theatre-media.test.js`는 로비 출입·층별 보행·의자 충돌·가려진 좌석·영사 음원과 수명을 검사한다. `tests/theatre-experience-browser.cjs`는 실행 중인 서비스에서 실제 모델·착석·무대 장면·영상 재생·무대효과·모바일 폭을 확인한다. 스크린 UV는 별도의 실제 HTMLVideoElement 사색 모서리 렌더 검사로 확인했다. 자동 Playwright 좌석 라벨 재조회가 Vite 갱신 도중 두 차례 시간 초과한 실험은 모델 문서에 한계를 기록했다.

이후 통합 브라우저 검사에서는 실제 2층 좌석을 선택해 앉고 일어서기, 1층 좌석에서 제공 영상 재생과 모바일 폭을 확인했다. Blender MCP로 새 사본을 열어 대극장 씬과 서울 기상 타이머 등록도 확인했다.
