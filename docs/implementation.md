# 세종문화회관 모델 구현 기록

## 기준 자료와 모델의 범위

제공된 사진과 배치 이미지, 대극장 종단면 도면을 참고해 Blender에서 세종문화회관 대극장과 별관의 외관 및 주변 광장의 일부를 재구성했다. 사용자 요청과 사진 23장의 개별 관찰은 [제작 브리프](brief.md)에 기록되어 있다. 최초 첨부 11장은 `docs/references/initial/`, 추가 첨부 11장은 `docs/references/additional/`, 후면 사진은 `docs/references/rear/`에 원본으로 보관한다. CAD 원자료 `5. All CAD Files.zip`은 사용자의 전체 커밋 요청에 따라 비공개 저장소에 포함하며 웹 빌드 출력에는 포함하지 않는다.

도면의 전면·후면 기준선 간 거리 112.5m, 객석 지붕 기준 높이 +35.060m, 무대 파라펫 +45.045m를 대극장 매스 배치에 참고했다. 112.5m는 도면상의 기준선 사이 거리이며 건물 외피 전체 길이로 단정하지 않는다. 원본 DWG를 변환할 때 일부 객체 이름 관련 경고가 있었으므로 치수는 원본과 교차 확인이 필요하다. 전면 폭과 사진에 가려진 부분, 녹청색 지붕의 마루 높이와 길이 등은 사진과 배치도에 근거한 추정이다. 이 모델은 실측·시공 도면이 아니다.

광화문 일대 전체는 구현하지 않았다. 이 모델은 회관 건물과 가까운 광장·식재에 집중하며, 인근 도로와 주변 건물, 광화문광장의 시설 전체를 지형이나 거리별로 재현하지 않는다.

회관 앞 포장 광장은 참고 사진에 보이는 깊이를 반영해 전면으로 확장했다. 돌 포장 줄눈과 보행 경계도 함께 연장했으며, 광장의 앞쪽 끝은 사진에 근거한 추정으로 도로나 전체 광화문광장을 복원한 것은 아니다.

## Blender 모델과 디테일

`scripts/build_sejong.py`는 석재 매스, 큰 지붕과 처마, 기둥과 기둥머리, 창호, 금속 격자, 별관 화면틀, 돌출 유리 공간, 연결동과 계단을 메시로 만든다. 사진 비례와 단면 기준에 따라 깊이·높이를 변환하고, 중앙 계단 36단을 최종 좌표에서 다시 만들어 단 높이를 균일하게 했다. 대극장 정면에는 로비로 이어지는 개구부 다섯 곳을 만들었다. 출입구 수와 배치는 사진에서 보이는 입면의 반복 구간을 따른 추정이며 실제 문 수는 확인되지 않았다. 석재와 포장재에는 Blender에서 생성한 미세한 질감이 쓰인다.

대극장 측면과 후면 기둥의 바닥을 지면까지 내리고 뒤쪽 기둥머리를 처마에 맞추었다. 별관 기둥 발치에도 지면에 닿는 받침을 만들고, 화면 본체에 외곽 틀과 지지대를 연결했다. 중앙 계단과 양쪽 옹벽 사이의 틈을 메우고, 난간 지주는 각 단의 받침과 경사진 손잡이 사이에 닿도록 높이를 조정했다. [추가 사진 6번](references/additional/image-6.png)과 [11번](references/additional/image-11.png)에 보이는 계단 옆 단차를 참고해 오른쪽에 여섯 단의 석재 화단을 만들고, 각 화단의 돌 받침을 지면까지 내렸다. 화단을 난간에서 떨어뜨려 지주와 돌이 관통하지 않게 했다. 화단의 정확한 실측 치수는 확인하지 못했다.

정문 유리 입면의 세로 창틀은 상부 보와 닿도록 높이와 깊이를 조정하고, 열린 문짝의 지주와 문틀 사이에 연결부를 만들었다. 광장 벤치 다리의 바닥 48개 정점은 Blender 편집 화면에서 직접 2cm 내려 포장면에 맞췄으며 재생성 스크립트에도 같은 크기를 반영했다. 계단 옆 화단의 잎은 화단면에서 시작하도록 만들었다.

대극장 정면 여섯 기둥의 머리는 사진의 벌어지는 형태를 참고해 열두 단면으로 곡선을 만들었다. 위아래 끝 크기와 상부 보에 닿는 높이는 기존 모델과 같으며 곡률은 실측이 아닌 추정이다.

같은 곡선형 기둥머리를 대극장 측면과 별관 정면에도 적용했다. 별관은 정면 사진에서 화면 양옆에 보이는 두 기둥을 남기고 화면 뒤로 드러나던 중앙 두 기둥은 제거했다. 별관 처마 아래 돌띠도 밑으로 좁아지는 경사면으로 만들었다. 사진에 가려진 구조와 경사 치수는 확인되지 않은 추정이다.

본관 정면의 큰 석재 피어에는 단마다 엇갈리는 수평·수직 줄눈을 두고 처마보 정면과 측면에도 판재 이음을 표현했다. 별관 테라스 측벽에도 석재 이음을 추가했다. 보조 석재와 별관 옹벽의 미세 질감은 Blender에서 직접 생성해 파일에 포함했다. 별관 옹벽에는 옅은 세로 풍화 표현을 더했다. 이 재질에는 참고 사진에서 추출한 픽셀을 사용하지 않았다. 이음과 질감의 간격·정도는 사진을 보고 정한 추정치다.

화강석·광장 포장·목재의 자체 생성 이미지도 선형 재질색을 sRGB로 인코딩해 GLB에서 의도한 색으로 해석되게 했다. 웹에서 이전 화면과 사진을 비교해 밝기를 조정했으나 조명·촬영 조건이 달라 실측 색상은 아니다.

소극장 돌출 유리실 아래에는 정면과 계단 쪽으로 이어지는 사각 홈 띠를 만들었다. 석재 틀 뒤에 어두운 면을 두어 깊이를 표현하고 상단을 슬래브에 맞췄다. 홈의 개수와 간격은 근접 사진을 토대로 추정했다.

대극장 전면 안쪽 처마 하부에는 근접 사진에 보이는 작은 조명 기구를 참고해 금속 테두리와 안쪽 렌즈를 만들었다. 다섯 기둥 사이에 두 개씩 배치했으며 개수와 간격은 사진을 바탕으로 한 추정이다.

정면의 격자 사이와 처마 아래에 짙은 유리 띠와 세로 창틀을 추가했다. 항공 사진을 참고해 대극장 상부 지붕의 전면 박공과 양쪽의 낮은 옥상 매스를 만들었고, 지붕 능선을 앞뒤로 연장했다. 창틀 간격과 옥상 매스의 용도·치수, 가려진 후면 지붕 형태는 추정이다.

지붕 확대 시 보이는 무늬는 그림자와 가는 지붕 이음의 앨리어싱이 함께 작용한다. 지붕의 미세 질감은 이 현상을 악화시켜 적용을 보류했다. 그림자 수신을 일부 끄는 방법과 높은 해상도·이방성 필터링을 각각 시험했으나 완전히 해결하지 못했고, 후자는 성능 부담이 커 적용하지 않았다. 현재도 확대 시 일부 무늬가 남는다.

중앙 계단 뒤 연결동에는 한 줄에 12개씩 두 줄의 좁은 창 개구를 만들고 유리를 벽면에서 약 0.47m 뒤에 배치했다. 각 유리 높이는 모델상 1.9m이며, 가로 줄눈은 개구에서 끊긴다. 대극장 측면 기둥이 두 창을 앞에서 가린다. 창 수·크기·깊이는 외부 사진을 근거로 한 모델의 추정이며 실측값이 아니다.

대극장 동측 긴 석재 벽의 작은 창 25개는 사진에 보이는 가늘고 긴 단창과 2~3개 묶음을 참고해 수평 줄에 배치했다. 벽 표면에 붙인 판 대신 외피를 나누어 홈을 만들고, 유리 앞면을 석재 면에서 약 0.29m 안쪽에 두었다. 창에 걸리는 석재 줄눈은 끊었다. 창의 수·위치·치수와 깊이는 사진을 참고한 추정이다.

Blender MCP의 측면 근접 캡처에서 비스듬한 방향으로 어두운 가로 띠가 나타난 적이 있다. 같은 위치의 정면 방향 캡처와 벽면 광선 표본에서는 벽이 연속이고 법선도 바깥을 향했다. 표본 검사는 모든 시점의 렌더링 문제를 배제하지 못하며, 캡처상 띠의 정확한 원인은 확정하지 못했다.

별관 전면 저층은 통석을 채운 매스 대신 바닥·지붕·벽과 지주가 있는 테라스로 구성하고, 세 곳에 열린 출입구를 두었다. 반투명 유리 뒤쪽에는 진열 가구와 간판을 배치했다. [최초 사진 8번](references/initial/image-8.png)과 [추가 사진 7번](references/additional/image-7.png)의 외관을 참고한 해석으로, 실제 점포 수·출입구 배치·실내 가구·간판과 입점 업체를 확인한 복원은 아니다.

별관 전면 대형 화면은 사진의 테라스 위 간격에 맞춰 화면 본체·프레임·직접 제작한 광고면을 함께 올렸다. 화면 아래에는 경사진 어두운 차양을 만들고 본체를 뒤 벽으로 연결하는 지지대를 두었다. 화면과 처마·테라스의 간격은 사진의 비례를 보고 정한 추정이며 지지대 구조도 사진에 가려져 있다.

후면 사진을 참고해 대극장 뒤에 여섯 기둥, 기둥머리, 상·하부 금속 격자와 유리 띠를 만들었다. 그 옆 긴 석재 별동에는 오목한 세로 창 21개, 기둥 일곱 개로 지지되는 열린 하부와 옥상 매스를 추가했다. 두 건물 접점 앞에는 정원 방향으로 내려가는 24단 계단과 착지판을 두었다. 건물 위치, 창 수, 계단 치수와 사진에 가려진 내부 동선은 추정이다.

`scripts/scene_details.py`는 위 스크립트에서 실행되며, 사진을 참고해 정문 앞뒤 방향과 건물 측면에 배치한 식재 구역, 나무줄기와 가지·잎, 지피 식물, 벤치와 광장 조명 형태, 로비 가구와 간판을 추가한다. 중앙 광장에는 널판과 줄눈을 표현한 3단 목재 데크가 있다. 수목은 다섯 가지 형태의 줄기·잎 메시를 여러 객체가 공유하고, 각 위치에서 높이와 회전을 달리한다. 좌우 부조는 곡선으로 직접 만든 얕은 형태이며, 사진의 문양을 추출하거나 투영하지 않는다. 나무 형태·배치와 가려진 부조 등은 사진에서 확인할 수 없는 부분을 해석한 것이다.

각 나무 밑에 화단 표면에 닿는 흙 부분을 만들고 지피 식물은 그 안을 피해 배치했다. 일곱 그루에는 줄기에 닿는 세 방향 목재 지주와 묶는 띠를 추가했다. 위치와 지주의 수는 사진의 식재를 참고한 해석이다.

중앙 계단 옆에는 참고 사진의 세로형 안내 표지를 바탕으로 별도의 본체·받침과 직접 만든 글자와 선을 배치했다. 표지의 위치와 문구는 사진에서 명확히 읽히지 않아 해석한 것이다.

수관은 개별 잎을 이전보다 작고 많이 배치하고, 지피식물은 화단에서 시작하는 여러 잎의 군락으로 만들었다. 낮은 관목은 18곳에 있다. 대극장 긴 측벽을 따라 화단을 뒤쪽으로 연장하면서 나무 네 그루를 더했으며 기존 나무 위치는 유지했다. 사진의 녹지를 참고했지만 새 수목의 정확한 위치와 높이는 추정이다. 나뭇가지와 잎은 여전히 단순화된 모델이다. 관목은 웹에서도 그림자를 드리운다.

나뭇가지를 꺾어 직선적인 방사형을 완화하고 잎 분포를 넓혀 수관을 더 풍성하게 했다. 수목 위치와 높이는 그대로이며 실제 수종을 정밀 복원한 것은 아니다.

후면 바닥을 연장하고 굴곡진 식재 구역 일곱 곳, 고정 배치한 수목 44그루와 낮은 식생, 굽은 산책로를 추가했다. 사진의 가을빛을 참고해 녹색·황록색·갈색 수관을 섞었다. 식재와 길의 배치, 수종 및 크기는 비실측 해석이며 사진의 울창한 정원을 완전히 복원한 것은 아니다.

전면 화단의 자연석 군락은 두 가지 Blender 형상을 시험했지만 사진의 거친 돌보다 다면체처럼 보여 적용하지 않았다. 사진에 보이는 자연석의 정밀 재현은 남아 있다.

대극장 앞의 큰 두 화단에는 자체 생성한 저대비 바닥 질감과 낮은 잎 군락을 더했다. 식물은 화단 표면에서 시작하고 나무 지주와 돌 테두리의 여유를 두었다. 식재 형태와 세부 배치는 사진을 참고한 해석이다.

인물형 부조를 개선하는 독립 시안을 두 차례 Blender에서 검토했지만, 인물과 옷자락이 사진의 조각과 충분히 닮지 않아 현재 모델에는 적용하지 않았다. 양쪽 부조의 정밀한 수작업 조형은 남아 있다.

모델을 검토하면서 실제 Blender UI에서 정면 보기로 전환하고 목재 데크의 X축 위치와 별관 점포 간판의 높이를 직접 조정했다. 광장 수목 한 그루도 Y축으로 +0.25m 이동했다. 별관 돌출 유리 공간의 배너 표면은 Blender UI에서 Y축으로 −0.005m 조정해 뒤판과 겹쳐 보이지 않도록 했다. 현재 스크립트에 이 조정들이 반영되어 있다.

[추가 사진 4번](references/additional/image-4.png)의 지상 유리 파빌리온은 [서울시의 S씨어터 소개](https://mediahub.seoul.go.kr/archives/1190167)에 나오는 지하 선큰 로비의 주출입구다. [세종문화회관 공식 안내 PDF](https://www.sejongpac.or.kr/portal/cmmn/file/fileDown.do?atchFileId=bedb1ae634e7404eaf5da097e359152e&fileSn=2)의 25쪽 배치도에서는 S씨어터가 M씨어터와 체임버홀 뒤쪽 방향에 표시된다. 이 지도는 극장의 대략적인 위치를 보여 줄 뿐, 유리 출입구의 정확한 배치와 치수는 확인되지 않았다. 사진 속 S씨어터 파빌리온은 현재 모델에 구현하지 않았으며, 별관 테라스에 돌출된 기존 유리 공간과는 별개의 시설이다.

[공식 공간안내](https://www.sejongpac.or.kr/portal/main/contents.do?menuNo=200357)의 입체 안내도에서도 S씨어터를 정원과 예술동 방향의 별도 공간으로 확인할 수 있다. 안내도는 계량 가능한 평면도가 아니므로 그것만으로 출입구의 정확한 좌표와 크기를 결정하지 않았다.

로비의 문, 가구, 조명과 간판은 실내 사진이나 실측으로 검증된 복원이 아니다. 걷기 경험을 위해 만든 가상의 실내이므로 실제 공간 구성으로 받아들이면 안 된다. 현재 모델에는 관객석이나 무대 전체를 탐색할 수 있는 실내가 구현되어 있지 않다.

## 벡터 그래픽과 사진 자료

별관 화면, 전면 현수막, 돌출 유리 공간의 가상 행사판은 직접 제작한 `assets/graphics/annex-screen.svg`, `annex-banner.svg`, `bridge-banner.svg`를 사용한다. SVG의 글자는 Noto Sans KR의 윤곽선이며, 사진이나 실제 공연 광고를 잘라 쓰지 않았다. 벡터 원본을 Chrome Headless로 래스터화한 PNG를 Blender 텍스처에 사용한다. 화면은 1440×960, 현수막은 3724×140, 행사판은 1440×360이다. 전면 현수막은 두 면에 같은 그림을 반복하지 않고 한 장의 양쪽 절반으로 나누었다. 행사판은 별관 모서리 기둥에 가리지 않도록 유리 공간의 보이는 면에 배치했으며 사진 속 행사의 복원은 아니다. 제작 및 폰트 출처는 [그래픽 설명](../assets/graphics/README.md)에 기록했다.

참고 사진 원본은 `docs/references/`에 자료로 보관하고, 현재 재생성된 모델의 부조·화면·현수막 재료로 사용하지 않는다. 과거에 만든 사진 기반 부조 크롭 이미지와 관련 Blender 데이터블록은 제거했다.

## 웹 뷰어와 조작

React와 Three.js 뷰어는 `public/model/sejong.glb`를 불러온다. 하늘과 구름은 웹 뷰어의 셰이더에서 만들고, 조명과 그림자도 Three.js 장면에서 설정한다. 건물과 수목이 그림자를 드리우며, 정적인 장면의 그림자 맵은 모델을 불러온 뒤 갱신한다.

Blender 원본에도 자연광 환경을 넣기 위해 하늘과 태양광을 두 가지 시점에서 렌더 시험했으나, 결과가 사진보다 어둡고 지평선이 부자연스러워 적용하지 않았다. 따라서 Blender 파일의 렌더용 하늘과 조명은 여전히 별도로 구성해야 한다.

- **모형 보기:** 드래그로 회전하고, 오른쪽 드래그로 이동하며, 스크롤로 확대·축소한다. 건물 표면을 마우스로 더블클릭하면 그 지점을 회전과 확대의 중심으로 삼는다. 화면을 선택한 뒤 방향키로 회전, Shift+방향키로 이동, `+`/`-`로 확대·축소할 수도 있다. `정면 보기`, `뒷면 보기`와 `처음 시점`으로 화면을 전환한다.
- **직접 걷기:** 화면을 드래그해 시선을 돌리고 `W`/`S`로 앞뒤, `A`/`D`로 좌우 이동한다. 위·아래 방향키는 앞뒤 이동, 왼쪽·오른쪽 방향키는 회전이다. 기본 이동 속도는 모델 좌표 기준 초당 2m이며 Shift를 함께 누르면 초당 5m로 이동한다. 화면의 방향 버튼을 길게 눌러 이동할 수도 있으며, `시작 위치`로 초기화한다. 키보드 조작은 뷰어 영역에 초점이 있을 때 사용한다.
- **전체 화면:** 지원하는 브라우저에서 뷰어를 전체 화면으로 열 수 있으며 모형 보기와 걷기 전환은 그대로 쓸 수 있다. 닫기 버튼이나 Escape로 원래 화면으로 돌아간다. 브라우저가 요청을 거부하면 안내가 나타난다.

걷기 모드는 광장에서 대극장 정문 계단을 지나 로비로 향하도록 구현했다. 본관 다섯 출입구와 별관 세 출입구에 맞게 충돌 제한 영역을 나누고, 돌출 기둥과 화단·테두리, 로비의 카운터와 벤치를 피하도록 했다. 목재 데크의 세 단에는 각각 보행 높이를 적용했다. `시작 위치`를 누르면 카메라와 입력 상태를 초기화하고 뷰어에 다시 초점을 주어 키보드로 계속 이동할 수 있다. 이동 제한은 전체 모델 메시의 정밀 충돌 검사가 아니라 미리 지정한 직사각형 영역을 사용하고, 계단과 착지 높이도 위치별 계산으로 정한다. 따라서 다른 장애물이나 세부 지형까지 물리적으로 정확한 충돌을 보장하지 않는다. 정적 나무 메시들은 같은 형상과 재질을 공유하는 경우 웹에서 인스턴스로 묶어 그리며, 원래 위치와 그림자 설정은 유지한다.

후면 정원까지 보행 범위를 늘리고 식재 구역과 별동의 기둥·벽을 피하도록 제한했다. 후면 계단과 착지에는 단별 높이를 적용했다. 충돌 영역은 직사각형 근사이므로 굴곡진 화단의 경계와 정확히 일치하지 않는다.

WASD 이동은 입력된 문자가 아니라 물리 키 위치를 우선 사용하도록 해 한글 자판 입력도 처리한다. 이벤트 단위 테스트로 확인했으며, 한글 IME를 켠 실제 기기에서의 검증은 남아 있다.

모드 및 시점 조작과 안내문의 크기·대비를 높이고 좁은 화면에서는 걷기 패드와 안내가 겹치지 않게 배치했다. 터치 포인터 환경에 손가락 조작 안내를 제공하지만 실제 터치 기기의 핀치 동작은 아직 검증하지 않았다.

로비 뒷벽의 보행 경계에는 카메라가 벽에 너무 가까워져 면을 잘라 보지 않도록 0.30m의 여유를 두었다. 장식 패널에 가까이 접근하면 화면이 어두워지는 현상은 여전히 남아 있다. 충돌 제한 거리를 조정하는 두 가지 방법을 시험했으나 각각 다른 방향에서 접근을 막지 못하거나 기존 통행을 방해하여 적용하지 않았다.

## 실행과 재생성

Node.js 환경에서 프로젝트 루트 기준:

```powershell
npm ci
npm run dev
```

프로덕션 웹 빌드는 `npm run build`로 실행하고 결과는 `dist/`에 생성한다. 이 작업 환경에서 확인한 버전은 Node.js 24.19.0, npm 11.17.0이다.

보행 제한의 가구 충돌과 출입구 통과 검사는 `node --test tests/walkCollision.test.js`로 실행한다.

Blender 5.2와 프로젝트의 `assets/graphics/` PNG 세 장이 있는 상태에서 프로젝트 **루트**를 현재 디렉터리로 하여 실행한다. 스크립트는 현재 씬의 객체를 지우고 `public/model/sejong.blend`와 `public/model/sejong.glb`를 다시 저장하므로 필요한 기존 파일은 먼저 백업한다.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python-exit-code 1 --python scripts/build_sejong.py
```

스크립트는 상대 경로로 `scripts/scene_details.py`와 PNG를 읽는다. 생성된 `.blend`는 Blender 편집용이며, `.glb`는 웹 뷰어용이다. Windows의 `C:\Windows\Fonts\malgun.ttf`가 있으면 로비와 별관 점포 간판 글자를 메시로 변환해 포함하고, 해당 파일이 없으면 이 간판 문구를 생성하지 않는다. 다른 운영체제나 Blender 버전에서는 경로와 호환성을 확인해야 한다.

## Cloudflare Git 연동

Cloudflare Pages 프로젝트 `blending-of-resejongnewpac`는 비공개 GitHub 저장소 `hslcrb/blending_of_resejongnewpac`에 연결되어 있다. 프로덕션 브랜치는 `main`, 빌드 명령은 `npm run build`, 빌드 출력 디렉터리는 `dist`다. 연결된 브랜치의 Git 변경을 Cloudflare가 빌드하는 방식이며 GitHub Actions 워크플로는 사용하지 않는다. 로컬 파일을 수정하거나 모델을 재생성한 것만으로 배포본이 바뀌지는 않는다. 저장소 반영과 Cloudflare 빌드 완료 여부는 별도로 확인해야 한다.
