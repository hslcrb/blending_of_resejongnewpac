# 전국 건물 변경 자료 제작과 검증 (2026-11-04)

`CH_D010_00_20261103`은 전국 건물의 **변경분**으로, 전체 건물 대장이나 현재 존재하는 모든 건물을 뜻하지 않는다. 원본 DBF의 변경 코드 `A29`가 신규(I) 또는 수정(U)인 레코드를 포함하고 삭제(D)는 제외한다. 동일 건물의 여러 변경 레코드가 존재할 가능성이 있어 최신 현황이나 중복 제거 결과로 해석하면 안 된다.

QGIS 3.44의 GDAL Python에서 SHP·DBF·SHX를 읽기 전용으로 열고 EPSG:5186을 유지한다. 건물 중심을 기준으로 10km 타일로 분할하며, 원본 행 번호(FID)와 `A0`부터 `A30`까지 31개 필드의 문자열을 보존한다. DBF 폭을 초과해 원본에 `*`로 기록된 값은 복원하지 않는다. 기본 도형은 타일 기준 0.1m 단위 정수로 저장하므로 좌표는 최대 0.05m 반올림될 수 있다. 고유 정점이 합쳐지거나 도형이 비유효해지는 레코드는 원본 정밀도 도형을 추가 저장한다. 각 타일은 gzip이며 크기, SHA-256, 전체 건수와 최대 도형 폭은 `manifest.json`에 기록한다. 빈 도형은 `unlocated.json.gz`에 필드를 남긴다. 웹에서 건물 경계를 검색할 때 중심 타일만 검사하면 경계에 걸친 도형이 누락될 수 있으므로 manifest의 최대 도형 폭만큼 검색 범위를 확장해야 한다.

원본은 사용자의 기존 QGIS 자료이며 별도로 제공된 공개 라이선스나 최신성을 확인하지 못했다. 서비스에서는 자료 범위와 이 한계를 명시한다. 서울 건물 점 자료와 서로 다른 원천이므로 FID를 하나의 공통 식별자로 취급하지 않는다.

재현은 저장소 루트에서 다음과 같이 한다. 출력 폴더는 아직 존재하지 않아야 하며 원본을 덮어쓰지 않는다.

```powershell
& 'C:\Program Files\QGIS 3.44.15\bin\python-qgis-ltr.bat' -B scripts/build_national_buildings.py --source '..\CH_D010_00_20261103\CH_D010_00_20261103.shp' --output 'public\gis\national-building-changes'
& 'C:\Program Files\QGIS 3.44.15\bin\python-qgis-ltr.bat' -B scripts/validate_national_buildings.py --source '..\CH_D010_00_20261103\CH_D010_00_20261103.shp' --output 'public\gis\national-building-changes'
```

검증기는 모든 타일의 크기와 SHA-256을 확인하고 레코드 중복, 포함 대상 누락, 31개 필드, 원본 도형 및 중심 좌표의 변환을 원본과 대조한다. 타일별 로드만으로 전체 최신 건물 재고를 제공한다고 주장하지 않는다.

생성 결과: 전체 97,984행 중 수정 97,827행과 신규 64행을 955개 타일에 보관했고 삭제 93행은 제외했다. 미위치 0건, 최대 도형 폭 946.5m, 압축 타일 합계 12,104,552바이트다.


## 정밀 형상 보존과 독립 검증

이전 0.1m 반올림은 원래 유효한 도형 70개를 비유효로 만들었고 그중 8개는 면적이 0으로 붕괴했다. 원본이 이미 비유효한 도형도 2개 있다. 고유 정점이 합쳐지거나 정수 도형이 비유효인 2,345개 레코드에 여섯 번째 선택 요소 `{"precision":"source","polygons":...}`를 추가했다. 배열 구조와 단위는 기존 polygons와 같은 타일 상대 데시미터이되 소수값을 유지한다. `NationalBuildingStore`는 이 요소가 있으면 정밀 좌표로 거리·포함 여부를 계산한다. 최초 다섯 요소는 모든 97,891건에서 이전 배포 자료와 동일하므로 중심점 인덱스와 기존 31개 필드의 배열 위치가 바뀌지 않는다. 오래된 소비자는 여섯 번째 요소를 무시하므로 정밀 검색에는 갱신된 로더가 필요하다.

검증기는 생성기의 도형 변환 함수를 호출하지 않고 원본 SHP에서 각 링·정점을 별도로 비교한다. 좌표 오차, 정점 및 고유 정점 수, 원본 유효 도형이 출력에서 유효한지, 원본 면적을 검사하며 정밀 예외는 원본 면적과 일치해야 한다. SHP·DBF·SHX의 입력 해시도 확인한다. 원본의 97,891건 모두 검증을 통과했고 정밀 예외는 2,345건이다. 기본 정수 도형은 의도된 0.1m 반올림 때문에 면적이 달라질 수 있으며 이 자료의 최대 절대 차이는 27.7117㎡다. 기존 5개 필드의 전수 호환 비교와 실제 초소형 FID 15479의 면적 내부 검색 테스트도 통과했다.
