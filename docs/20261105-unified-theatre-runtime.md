# 외관과 대극장의 단일 모형 런타임 - 2026-11-05

기존 `TheatreExperience`의 대극장 GLB, 로비 구성, 좌석 목록, 무대막·반사판·영사, 공간 음향 및 보행 함수를 재사용한다. 운영 진입점은 별도 실내 React renderer 대신 기존 `BuildingViewer`의 **같은 scene, camera와 renderer**를 이용한다. `/explore/`에서 광장 → 전면 계단 → 유리 출입구 → 로비 → 객석 → 무대·뒤편으로 걸어 들어가고 같은 출입구로 나올 수 있다. 기존 `?theatre=1` 주소는 이 같은 모형의 걷기 모드로 열리며 별도 장면을 만들지 않는다. 지도 `/map/` 경로와 내장 모드는 보존한다.

## 공간 계약

기존 실내의 Y-up 좌표를 uniform scale 1.25와 campus translation `[33.1, 1.07, -71.9]`로 배치한다. 로비 입구 local `[0,0,60]`은 campus `[33.1,1.07,3.1]`에 놓인다. 대극장 단계 바닥과 로비 경사로의 높이를 같은 world 좌표로 변환하므로 입구에서 임의의 scene 전환이나 카메라 순간 이동이 일어나지 않는다. 실내 벽·의자·로비 기둥은 실내 보행 규칙으로 검사하고, 외부에서 옆 벽을 가로질러 들어가는 이동은 차단한다. 뒷무대가 외피 안에 들어가도록 한 파생 `grand-theatre-campus.glb`를 사용하며 local z -10.24 뒤의 왼쪽 보행 경계는 -7m다.

## 재사용과 동작

`createUnifiedTheatre()`는 `detail` 그룹에 기존 실내와 로비를 부착한다. 기존 좌석 ID와 1·2·3층 배치를 사용하고, 앉기는 같은 camera의 위치·시선만 조절한다. 일어서면 같은 층 통로에 선다. 무대 제어와 사용자 영상은 기존 `createTheatreMedia`를 사용하며 HRTF 음원은 스크린에 남는다. 페이지를 숨기면 미디어를 일시 정지한다. 내부 밝기는 실내에 있을 때만 기존 노출 보정을 적용한다. 앱 종료 시 비디오·오디오·GLB·로비·선택 타깃의 자원을 정리한다.

## 검증

`tests/theatre-placement.test.js`는 입구 좌표, 역변환, 외부에서 실내로 연속 이동, 옆 벽 통과 차단과 바닥 높이를 검사한다. `tests/unified-theatre.test.js`는 실제 Three 그룹에서 실내가 외부 그룹 자식인지, 한 camera로 좌석에 앉는지, 무대막 제어와 정리가 동작하는지 확인한다. 기존 GLB 원본과 이전 실내 소스는 보존하지만 운영 `main.jsx`에서는 별도 `TheatreExperience`를 로드하지 않는다.
