# 행정경계·전시천리안 화면 연결 (2026-11-04)

## 동작

기존 3D 화면에 `행정·지면 경계` 토글을 추가했다. 지도 배경, 돋보기 또는 전시천리안이 활성화되어 있고 이 토글이 켜져 있으면 사용자 제공 QGIS 백지도의 시도·시군구·행정선·하천·도로·철도와 별도 행정동 자료를 같은 장면에 표시한다. 경계선은 유형별로 묶어 그리며 깊이 충돌을 피하도록 모형 위에 투사한다. 원본 QGIS 백지도의 소축척·출처 미확인 한계와 행정동의 2026-10-01 기준, 법정동 및 지적경계와의 차이, SGIS·vuski/admdongkor·CC BY 4.0 출처를 화면에 표시한다.

돋보기에서 선택한 지점 또는 현재 중심/건물 검색 결과의 좌표를 기존 건물 정보와 공유해 행정 폴리곤과 주변 선을 조회한다. `행정경계 · 지면 정보`에 포함 여부·거리와 모든 원본 필드를 페이지별로 표시한다. 위치는 클릭한 3D 모형·서울 50m 격자에 따른 근사치이며 실제 지적 판정을 위한 것이 아니다. 전시천리안에서는 같은 투사 캔버스에 행정구역과 기존 건물 이름을 함께 배치하고, 다른 레이블뿐 아니라 지도 출처·조작 버튼·힌트 영역도 피하도록 위치를 조정한다. 화면 크기에 따라 행정 이름 최대 36개와 건물 이름 최대 25개를 표시한다. 전국 고도에서는 광역 이름을 우선하고 상세 이름은 확대하거나 선택해 확인한다.

`전국 행정동 전체 보기`는 16개 광역권 행정동 전체를 불러오고 전국 시점으로 이동한다. 모든 권역의 선과 최대 3,559개 행정동 이름 데이터는 사용할 수 있으나 글자는 화면 겹침 때문에 일부만 동시에 표시한다. 3D 개별 건물 695,753건은 서울 자료이며 전국 건물 전체를 뜻하지 않는다. 기존 전국 문화·집회시설 목록 역시 2026-11-03 변경 자료의 후보일 뿐 전국 전체나 현재 운영 시설 목록이 아니다.

일반 서울 화면에서는 화면 절두체와 지면의 교차 범위를 EPSG:5186으로 바꾸고, 소축척 시도 폴리곤의 외접 사각형과 겹치는 광역권을 지연 로드한다. 외접 사각형은 보수적인 근사치라 경계 바깥 인접 권역을 함께 불러올 수 있다. 350km보다 넓은 시야에서는 자동으로 전국 전체를 내려받지 않고 중심 권역만 읽는다. 사용자가 전국 전체 보기 버튼을 눌러 16개를 명시적으로 요청할 수 있다. 회관/서울 모드의 서울 자치구·행정동은 기본으로 로드한다. 요청 오류는 상태와 `경계 자료 다시 불러오기`를 표시한다. 화면 해제 시 모든 메시·자원·진행 요청을 정리한다.

## 검증

- `node --test tests/geography-view.test.js tests/geography-layer.test.js tests/geography-real.test.js tests/admin-dong.test.mjs`: 지역 코드, 소축척 범위 대조, 좌표 축, 서울 종로구·행정동·도로 속성, 부산 행정동, 가시성·오류·재시도·해제와 원자료 무결성을 확인한다.
- `node tests/geography-ui-browser.cjs`: 실제 앱의 건물 검색에서 종로구 속성, 전시천리안 이름 투사, 전국 16권역 로딩, 390px 화면, 걷기 전환, 경계 요청 실패·재시도를 검사한다. 외부 지도 서버의 자동화된 대량 요청을 피하기 위해 이 검사에서 외부 타일은 로컬 모의 이미지로 응답한다.
- `GEOGRAPHY_EVIDENCE_PATH`를 지정하면 전국 시점의 3D 캔버스를 저장한다. 이 이미지는 경계와 레이블 확인용으로, 모의 지면 타일을 썼기 때문에 실제 지도나 위성사진을 입증하지 않는다.

최종 운영용 Vite 빌드는 성공했고 전체 Node 검사 82개가 통과했다. 첫 전체 검사에서는 독립 worktree의 sparse checkout에 기상 API 파일이 없어 1개가 실패했으며 `/functions/`를 추가한 뒤 모두 통과했다. 전국 화면 시각 검토에서 한반도 북부와 제주를 포함하도록 카메라를 조정하고 중복 광역명과 출처·조작부 겹침을 줄였다. `geography-integration.png`는 외부 타일을 모의 응답한 검증 이미지다.
