# 낮과 밤의 하늘·회관 조명 (2026-11-04)

기존 회관 장면은 자정에 하늘 주변광이 0.32, 보조광이 0.24까지 내려가 입면과 보행 영역의 경계가 어두워졌다. 같은 카메라에서 자정 기준 건물·광장 일부의 평균 화면 밝기는 57.8/255였다. 태양 고도를 기준으로 주변광 하한을 0.67, 보조광 하한을 0.44로 조정하고 회관 좌표에 따뜻한 조명 네 개를 둬 일몰 후 서서히 켠다. 기본 장면과 서울 장면을 전환할 때 회관과 함께 조명이 이동하며, 낮에는 꺼진다. 야간 바탕지도 밝기 하한도 0.35에서 0.5로 조정했다. 이것은 실제 현장 조도 실측이 아닌 보기 편한 표현이다.

하늘은 기존 서울 시각·NOAA 태양 근사와 김포공항 METAR 구름 분류를 유지한다. 달의 위치·밝은 면은 저정밀 달 궤도에서 계산하며, 달이 지평선 아래면 보이지 않는다. 별은 시간에 따라 돌아가는 **절차적 장식**으로, 실제 별자리 관측이나 현장 사진은 아니다. 달 크기는 식별하기 쉽도록 실제 시지름보다 다소 크게 표시한다. 김포공항 기상은 광화문의 현장 관측이 아니며, 구름 위치와 형상도 근사다.

USNO의 [천체 항법 API](https://aa.usno.navy.mil/data/api.html)와 2026-11-04 21:00 UTC, 서울 37.572° N, 126.9763° E를 비교했다. USNO 지구중심값은 달 고도 36.0464°, 방위 120.4056°, 밝은 면 19%; 구현은 각각 약 35.67°, 119.44°, 18.8%다. 위치는 저정밀 지구중심 근사라 관측자의 시차, 지형, 대기 굴절 등은 반영하지 않아 천문 관측용으로 사용하지 않는다.

검증 시 정오·자정, 구름 없는 하늘, 동일 고정 카메라로 회관·광장과 걷기 화면을 비교했다. 자정 영역 평균은 105.2/255로 증가했고 정오 영역 평균은 189.1에서 190.8/255로 유지됐다. 브라우저 독립 WebGL 장면에서 달·별의 실제 출력과 낮·밤 밝기 차이를 확인했고 JavaScript/셰이더 오류는 없었다. 이 값은 스크린샷 샘플의 비교이며 조도 실측이나 모든 사용자 화면의 보장은 아니다. 소프트웨어 WebGL에서는 전체 장면을 올려다보는 추가 화면 촬영이 시간 초과해, 별·달은 작은 독립 셰이더 장면에서 검증했다.

재현: `node --test tests/skyState.test.js tests/night-sky-lighting.test.js tests/sky-visual.test.js`. Vite 개발 서버를 `127.0.0.1:3158`에 띄운 뒤 `node tests/sky-visual-browser.cjs`를 실행하면 WebGL 렌더링과 낮·밤 화면 밝기를 확인한다. 필요하면 `AREA_TEST_ORIGIN`과 `CHROME_PATH`를 지정한다.

## 2026-11-04 추가: 외부 모델과 대극장 뷰포트 밝기

외부의 야간은 주변광 0.67/보조광 0.44로 설정돼 있었고 반대 방향에서 실내나 입면이 어두웠다. 낮의 최대값 1.40/0.72는 유지하면서 밤의 하한을 0.82/0.56으로 조정했다. 대극장은 밝은 로비와 어두운 객석을 하나의 노출 1.18로 그려 로비는 충분히 밝지만 적갈색 객석과 막의 디테일이 가려졌다. 카메라가 로비에서 객석으로 이동할 때 노출을 1.18에서 최대 1.48까지 부드럽게 조정한다. 영상 텍스처는 `toneMapped=false`라 영상의 자체 색과 명암은 이 노출에 영향을 받지 않는다.

동일 카메라의 Chrome 소프트웨어 WebGL 캡처에서 객석 상단·좌석 영역 평균 RGB는 84.2/21.0/16.7에서 97.3/26.1/20.8로 증가했고, 같은 로비 영역은 199.6/176.2/148.9로 유지됐다. 서울 전역의 같은 영역 평균 RGB는 정오 210.6/207.2/184.0으로 유지되고 자정은 166.7/162.4/143.3에서 168.7/164.4/145.2로 변했다. 이는 동일 테스트에서의 상대적인 화면값이며 실제 조도나 모니터별 밝기 보장은 아니다. 사용자 영상의 재생 및 공간 음향, 무대효과, 좌석 이동도 다시 실행했다.

Blender에서 열린 대극장 사본의 3D 뷰는 SOLID 모드여서 장면 조명과 실제 월드를 사용하지 않았다. 미저장 변경이 없는 것을 확인하고 현재 뷰를 MATERIAL 모드, 장면 조명·월드 사용으로 바꾸자 객석·막의 조명과 실제 시각 연동 월드가 반영됐다. 3D 화면 설정은 원본을 덮지 않고 대극장 작업 사본에 저장했다. 15개 씬, 1,704개 객체, 866개 메쉬 및 전체 정점·폴리곤 형태의 SHA-256 `568629f378e2014e4381f589d8d227ade17b9beb64cc514a6b3e72f5388e5c23`은 변경 전과 일치한다.

다른 서울 하늘 사본도 기존 `open-seoul-sky.cmd` 또는 대극장용 `open-grand-theatre.cmd`로 열면 `scripts/start_blender_weather.py`가 시간·기상 타이머와 함께 `scripts/blender_viewport_lighting.py`의 뷰 설정을 적용한다. 이 설정은 사용자의 Blender 전역 설정을 건드리지 않는다. 실행 뒤 각 3D 뷰의 Material Preview에서 장면 조명 및 장면 월드를 끄면 사용자가 직접 다른 보기로 전환할 수 있다. Blender 배경 실행으로 사본을 다시 열어 저장된 10개 3D 뷰의 설정과 기상 타이머 시작을 검증했다.
