# 세종 3D 서비스 통합 설계와 실행 계획 (2026-11-04)

> 이 문서는 구현 전에 양쪽 저장소에 기록한다. 사용자가 경로와 방안 선택을 위임했으며, 아래는 확인된 사실과 구현자가 선택한 설계다. 작업을 진행하며 실제 결과와 변경된 결정을 별도 기록한다.

## 목적과 현재 상태

`blending_of_resejongnewpac`을 `ㄴ더ㅐㅜㅎ/blenderssejong`에 클론하고 세종문화회관·파빌리온·광화문·서울 및 전국 문화시설 안내를 하나의 실시간 3D 서비스로 발전시킨다. `renewsejongpac`의 현재 둘러보기는 이 서비스의 내부 경로를 이용해 같은 기능을 제공한다. 두 GitHub 저장소는 각각 Cloudflare Pages와 연결되어 `main` 커밋에 따라 자동 배포되며 GitHub Actions로 대체하지 않는다.

확인 기준: 기존 `renewsejongpac` main `1441fe44061f7e1c17ed8d8548d28013715de8fe`, 3D 저장소 main `74b51d83d694506b4fee8cb6c41eeeec0d85b751`. 기존 웹은 광화문 GLB와 서울 50m 격자, 695,753건 건물 위치·29개 원본 필드·664개 공간 타일·25개 검색 색인을 사용한다. 새 서비스는 React/Vite/Three.js, 분할 GLB 스트리밍과 걷기 기능을 사용하며 파빌리온과 정원·카페가 포함돼 있다. 두 모형 좌표는 같은 계열로 보이나 겹쳐 검증해야 한다.

## 설계와 대안

1. 기존 리뉴얼 웹 내부에 3D를 계속 복제하는 대신 새 서비스가 공간 모델, GIS 조회, 하늘과 상호작용의 단일 소유자가 된다. 대안인 화면별 별도 구현은 모델·기능 불일치를 만든다. 기존 서비스의 파빌리온과 걷기·분할 로딩을 유지하고 GIS 광화문과 서울 데이터를 좌표 기준으로 통합한다.
2. 새 서비스에 독립적으로 접근 가능한 버전 지정 경로와 임베드 모드를 제공하고, 리뉴얼 사이트는 `https://live.renewsejongpac.rhee.life/`의 해당 내부 경로를 반응형 iframe으로 사용한다. 직접 이동 링크와 실패 안내도 둔다. 부모와 자식이 상태를 주고받을 필요가 있다면 출처와 메시지 형식을 명시적으로 검증한다. iframe 및 모바일·키보드 조작, 접근성 이름, WebGL 오류를 확인한다.
3. 필요한 자료는 새 저장소에 먼저 복사해 검증하고 양쪽 서비스 전환을 확인한 뒤 중복을 정리한다. 원본 외부 사용자 GIS와 기존 파일을 임의로 훼손하지 않는다. Blender 프로젝트 전체 씬, 패킹된 이미지, QGIS 프로젝트의 상대경로 GeoPackage와 재생성 스크립트를 보존한다. Git의 과거 이력은 재작성하지 않는다.

## 데이터·좌표·출처 계약

- 회관 로컬 Blender X=N−552531, Y=197897−E; 서울 Three.js `(E−200000, 높이, 550000−N)`. EPSG:5186 원본과 GeoPackage의 EPSG:5179를 변환하고 현장 사진·건물 폴리곤·파빌리온을 함께 검증한다. 실제 위치·높이와 사진 해석의 오차를 표시한다.
- `CH_D010_00_20261103`은 97,984건의 변경 자료로 보이며 D 93건, U 97,827건, I 64건이다. 삭제 레코드를 현재 건물로 표시하지 않고 전체 전국 건물 데이터라고 주장하지 않는다. 법정동+지번은 도로명 주소가 아니다. EUC-KR/CP949, 누락·NUL·숫자 오버플로를 처리하고 원본값과 출처를 보존한다. 문화·집회 용도 후보 347건은 실운영 공연장으로 검증되지 않았다. 다른 지역 문화시설 소개는 검증된 자료와 후보를 명확히 구별한다.
- QGIS 자료의 시도·시군구·행정경계·해안선·하천·도로를 조사하고 확대 수준에 맞는 경계 레이어로 변환한다. 축척이 낮은 백지도 경계를 상세 지적 경계로 가장하지 않는다. 별도 SVG는 초기 조사에서 발견되지 않았으므로 추가 확인한다. 지역 경계와 건물의 실제 원본 필드를 돋보기와 전시천리안에서 확인할 수 있도록 한다.
- 실제 지면지도와 위성지도는 제공자의 라이선스·출처 표기·브라우저 접근·요청량 정책을 확인해 사용한다. 가능한 선택지는 [OpenStreetMap 타일 정책](https://operations.osmfoundation.org/policies/tiles/)에 따른 화면에 보이는 타일과 [EOX Sentinel-2 cloudless](https://cloudless.eox.at/documentation/faq)의 상업 이용 가능한 2016년판이다. 2016 위성사진은 10m급이며 현재 촬영 영상이 아님을 표시한다. 보다 선명한 VWorld 영상은 발급된 인증키와 사용 조건 확인이 필요하다. GeoPackage 자체의 정확한 제작기관·이용조건은 미확인으로 남겨 확인한다.

## 실행 작업과 검증

- [ ] 양쪽 저장소와 Cloudflare Pages의 main 자동 배포·현 서비스 상태를 확인하고 이 계획을 양쪽에 커밋·푸시한다. 이후 구현에 착수한다.
- [ ] `gis-sejong`의 Blender 3개, QGIS 프로젝트와 상대경로 데이터, 내보내기 도구 및 기존 건물 타일·검색·광화문 GLB·서울 격자를 새 저장소에 정리해 복사한다. 원본/복사본 해시, Blender 전체 씬과 외부 의존성, GIS 타일 개수와 원본 필드를 확인한다.
- [ ] 기존 파빌리온·걷기·분할 스트리밍을 보존하면서 광화문과 서울을 정합하고 지역 전환을 구현한다. 같은 장소의 중복 건물과 지면 충돌을 점검한다.
- [ ] 돋보기, 건물 주소·원본 속성·경계, 서울 전체 검색, 전시천리안 투사와 접근 가능한 목록을 새 서비스에 구현한다. 표시 밀도·실제 데이터 미기재·좌표 오차는 숨기지 않는다. 695,753건의 29필드를 동시에 읽을 수 있다고 가장하지 않는다.
- [ ] 백지도와 행정경계, 화면에 표시 가능한 실제 지면·위성 지도를 추가한다. 데이터 범위, 출처·촬영 시점, 서비스 장애와 이용조건을 화면과 문서에 기록한다.
- [ ] 전국 건물 변경 자료를 필요한 필드와 용량에 맞게 처리하고 삭제·불명확 상태를 구별한다. 검증 가능한 문화시설 안내를 추가하고 자료가 전국 완전 목록이 아니면 그 사실을 밝힌다.
- [ ] Blender 작업 복사본과 웹의 모든 관련 장면에 서울 현지 날짜·시각 기반 태양 위치, 24시간 조명과 실제 관측 날씨/구름 반영 및 실패 시 명시적 대체를 구현한다. Blender 자동 실행 보안과 애니메이션/실시간 갱신 동작을 검증한다. 기존 사진 검토 씬과 야간 씬은 보존하고 장면별 적용 여부를 기록한다.
- [ ] 각진 나뭇잎을 잎처럼 둥글고 끝이 가늘어지는 형태로 개선하고, 잎과 가는 가지·굵은 가지가 실제로 연결되도록 Blender와 스트리밍 GLB를 갱신한다. 시각 증거와 지오메트리/성능을 함께 검증한다.
- [ ] 새 서비스 운영 배포와 데이터 응답을 Cloudflare MCP 및 실제 브라우저에서 검증한 후 리뉴얼 화면을 연결한다. 전환 전·후 URL, 두 main SHA·배포 ID·결과를 기록하고 각 단계에서 커밋·일반 푸시한다.
- [ ] 이전 자산을 실제 의존성이 없는지 확인한 후 정리하고, 두 사이트의 자동 배포가 `main` 푸시에 반응하는지 확인한다. 최종 전체 테스트와 광화문·서울·전국, 모바일, 확대·회전·걷기·돋보기·전시천리안·날씨·실패 복구를 공개 운영 환경에서 검증한다.

## 중점 실패 조건

- 좌표계·축·높이 차이 또는 고도 없는 지도 타일 때문에 건물과 경계가 어긋난다.
- 분할 모델 로딩과 중복 제거가 기존 파빌리온·걷기 충돌을 망가뜨린다.
- 불완전한 전국 변경분 또는 오래된 위성영상을 현재 완전 자료로 오인한다.
- 69만 건 메타데이터의 다운로드·투사·검색이 모바일에서 멈추거나 접근성을 잃는다.
- 교차 출처 iframe, 지도·날씨 제공처 실패, 사용자 위치와 무관한 시간대가 화면을 깨뜨리거나 잘못된 상태를 표시한다.
