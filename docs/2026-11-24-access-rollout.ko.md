# 세종문화회관 3D 접근 범위 전환 기록

**2026-11-24 KST**. 웹 접근과 GitHub 저장소 공개 범위를 별개로 점검했다.

## 변경 순서

1. GitHub 저장소를 이미 비공개 상태임을 메타데이터로 확인했다. 저장소 접근 권한을 확대하지 않았다.
2. 기존 DNS 전용 CNAME은 대상 변경 없이 프록시만 켰다. HTTPS 302를 확인했다.

## 사이트 적용과 검증

- 운영 주소: `live.renewsejongpac.rhee.life`.
- Pages 기본 `blending-of-resejongnewpac.pages.dev` 및 배포 하위 도메인에 별도 정책을 붙였다. 프리뷰와 원본 주소도 운영 주소의 인증을 우회하지 않도록 확인했다.
- Access 앱과 두 허용 정책 모두 사이트 세션 10분. 이메일 PIN은 공급자 기본 만료 10분. Google 로그인과 이메일 PIN은 승인된 서로 다른 계정에 연결했고, 우회 및 전체 도메인 허용 규칙은 만들지 않았다.
 - 새 인증 쿠키 없이 요청한 검증은 Access 로그인으로의 HTTP 302로 확인했다. 개별 계정으로의 인증 성공까지 검증했다는 뜻은 아니다.
- 전환은 기존 공개 복제본이나 브라우저에 이미 내려받은 파일을 회수하지 않는다. 인증 계정과 정책 식별자는 이 문서에 저장하지 않는다.

## 3D 운영 변경과 CMS의 범위

이번 기록의 대상은 세종문화회관 정적 3D 사이트다. 별도 CMS 과제 저장소의 편집기, BaaS 및 게시 권한은 변경하지 않았다. 커스텀 호스트의 기존 CNAME 대상은 유지됐고 프록시 적용 뒤 Pages 별칭과 별개로 인증 응답을 확인했다. 로그인 뒤 모델 가시화는 새로 측정하지 않았다.

## 공통 검산 절차와 기록 범위

저장소 공개 여부와 배포 주소의 접근 제어를 별도로 확인했다. 접근 정책은 두 로그인 수단을 각각 지정된 계정과 묶고, 세션 10분과 이메일 일회용 코드의 만료 10분을 구분했다. 세션이 끝나도 상위 로그인 상태에 따라 인증 화면 동작은 달라질 수 있으므로, 항상 코드를 다시 입력해야 한다는 뜻은 아니다. 사이트가 있는 경우 로그인 화면으로의 응답을 확인하는 절차는 비인증 검산이다. 로그인 뒤 장면 표시와는 구분하고, 정책 식별자·계정 주소·쿠키·인증 코드를 이 개발기에 적지 않았다.
