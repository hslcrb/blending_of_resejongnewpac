# 기존 대극장 내부를 외관 안에 넣는 개조 — 2026-11-05

사용자 요구: 기존 대극장 내부와 URL을 보존하고, 기존 외관 모델 안에 내부를 실제 배치하여 광장에서 유리문을 지나 로비·객석·무대·백스테이지로 연속 보행한다. 별도 장면 전환이나 빈 외피로 대체하지 않는다.

- 최신 main fetch/pull 완료. 리뉴얼 저장소는 다른 작업 브랜치와 미추적 파일이 있어 보존한다.
- 기존 수목/서울 하늘 Blender 사본을 새 작업 사본으로 저장하고 MCP로 본관을 편집한다. 기존 joined material mesh의 본관 부위를 분리해 내부를 막는 덩어리와 지면을 실제 벽·슬래브·개구부로 바꾼다.
- 이미 만든 grand-theatre 좌석·막·음향반사판·스크린·무대 뒤편과 로비 구조를 재사용한다. 내부→외부 Three 좌표 변환은 scale1.25, translation [33.1,1.07,-71.9]. 내부 로비 z60은 본관 출입구 [33.1,1.07,3.1]에 놓는다.
- 첨부 항공사진의 지붕·열주·별관과 중앙 대계단, 유리·식재를 비교해 수정한다. 분홍 표시는 계획 범위 표시이므로 지붕 색으로 만들지 않는다.
- 웹은 하나의 scene/camera 안에서 외부와 내부를 같이 구성하고 기존 대극장 URL은 같은 장면의 내부 진입 위치로 유지한다. /map/ GIS와 기존 영상·착석·서울 하늘을 보존한다.
- 같은 씬의 내부가 외피 bounds에 포함되는지, 출입구/통로·충돌·좌석·영사·유리 투과·낮밤을 검증하고 사본·생성 스크립트·배포 자산을 커밋/푸시한다.

사진과 기존 도면 기준의 재구성이며 확인할 수 없는 공간의 실측 정확성을 주장하지 않는다. 원본과 과거 사본은 보존한다.
