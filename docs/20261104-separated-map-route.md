# 회관 산책과 지도 경로 분리 - 2026-11-04

기존 `/explore/` 및 `/`는 세종문화회관과 광화문 주변 3D 산책에 집중한다. 모형 보기, 직접 걷기, 대극장 내부 체험과 서울 시각·하늘은 유지한다. 기본 화면은 지도 타일·행정경계·건물 GIS 정보를 불러오지 않는다.

`/map/`은 기존 지도·위성지도, 광화문/서울 전환, 돋보기, 전시천리안, 전국 경계·건물·문화시설·도로 자료를 유지하는 별도 체험이다. 기본 화면의 **지도·전시천리안** 링크로 진입하며, 지도의 **회관·광화문 보기**로 돌아간다. 리뉴얼 사이트에 내장한 `/explore/?embed=1`에서는 지도 링크를 독립 탭으로 열어 부모 화면을 유지한다. 대극장 링크 및 버전이 지정된 iframe 높이 통지는 그대로 유지한다. 정적 파일은 복제하지 않고 두 경로에서 동일한 모델과 기존 원본 데이터를 사용한다.

## 검증 결과

- `tests/separated-map-browser.cjs`: 기본 내장 화면의 지도 도구 부재, GIS 자료 요청 없음, 대극장·별도 지도 링크, 320/390/500/1200px 폭, `/map/`의 전시천리안과 전국 건물 97,891건 표시 통과.
- `tests/seoul-tools-browser.cjs`: 새 `/map/` 경로에서 건물 29개 필드·검색·지도 출처·전국 후보 위치 통과.
- `tests/embed-browser.cjs`: 기존 `/explore/?embed=1` 내장 화면·모바일 조작 통과.
- `tests/experience-routes.test.js`: 독립 경로와 내장 복귀 URL 통과. Vite 빌드 통과.
- 미해결 검사: `tests/national-map-ui-browser.cjs`는 시설·지형 레이어 20개를 검증할 때 `.national-map-options input:checked`가 동일 클래스를 사용하는 도로 체크박스 3개도 포함하여 `23 !== 20`으로 실패했다. 범위를 `.national-map-controls`로 좁힌 재시도도 양쪽 섹션이 동일 클래스를 공유하여 같은 결과였다. 두 번의 실패 후 사용자 지침에 따라 재시도를 중단했고, 불완전한 선택자 변경은 되돌렸다. 이 결과는 분리된 지도 전체 흐름이 통과했다는 증거가 아니므로 별도 확인이 필요하다.
