# 세종문화회관 공개 동선 및 광화문 북축 구현 계획

**목표:** S씨어터 지상 입구와 지하 선큰의 관계, 감사의 정원 지상 조형과 지하 입구, 광화문·월대와 북측 광장을 실제 자료에 근거해 보정한다.

1. 동선과 치수 출처를 구분하고 기존 Blender와 웹 청크의 월드 원점을 확인한다.
2. 기존 편집본 및 GLB는 그대로 두고, 링크 가능한 Blender 컬렉션과 다운로드 가능한 청크로 보정한다.
3. 기존 S씨어터 개략 형상과 바닥을 새 GLB가 로드되어 확인된 경우에만 함께 대체하고, 정원과 북축은 기존 스트리밍을 사용한다.
4. GLB와 manifest 크기·물리·누락 대체를 검사하고, 같은 카메라 전후 렌더와 자료별 확신 수준을 상세 개발기에 남긴다.
