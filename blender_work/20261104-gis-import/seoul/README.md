# 서울 건물 분포 개요

## 열기

- `seoul_buildings_overview.blend`: Blender에서 여는 서울 전역 개요. 구 코드별 25개 메시와 전체 카메라가 있다.
- `seoul_overview.qgz`: 같은 폴더의 `seoul-grid-50m.gpkg`를 상대경로로 읽는 QGIS 프로젝트다. 두 파일을 함께 보관한다.
- `seoul-grid-50m.json.gz`: 두 결과에 사용한 집계 데이터. 지번 등 원본 속성은 포함하지 않는다.

## 데이터와 표현 범위

사용자가 보유한 `AL_D010_11_20261009.shp`는 EPSG:5186 미터 좌표의 건물 폴리곤이다. 서울 코드(A23 `11`로 시작)를 가진 695,753개 중 넉넉한 좌표 검사 범위(E 175000~225000, N 530000~575000m)를 벗어난 이상치 2개를 빼고 695,751개를 집계했다. 이 범위는 **행정 경계가 아니다**. 원본의 출처·이용 조건 및 해당 파일의 공식 필드 정의는 확인하지 못했다. 유사한 [국토교통부 GIS건물통합정보 메타데이터](https://www.data.go.kr/catalog/15083092/fileData.json)는 공공누리 제1유형을 명시하지만 이 로컬 사본과 동일한 배포본인지는 미확인이다. [AL_D010 분석 사례](https://github.com/Cho-Woojin/dormitory-site-selection/blob/main/docs/DATA_SOURCES.md)의 A16·A26 해석은 2차 자료다.

각 폴리곤의 중심점을 50m 격자로 묶어 건물 수 및 높이 평균을 저장했다. 구 경계 342개 격자는 중복 없이 합치고 구별 기여 건수는 별도 속성에 남겼다. Blender에서는 각 격자를 건물 수가 가장 많은 구의 메시에 배정한다. 따라서 구 메시의 `buildings_in_assigned_cells`에는 경계 격자에서 다른 구에 속하는 건물도 포함되며 해당 구의 실제 건물 총계가 아니다. Blender의 사각 기둥은 **격자별 요약**으로, 실제 건물의 윤곽·위치별 높이·행정 경계가 아니다. 배경 사각형도 행정 경계가 아니며 강·도로·지형 모델은 포함하지 않는다. 높이에 수직 과장은 적용하지 않았다.

A16의 양수값(최대 500m 허용)을 높이 후보로, 없으면 A26 층수에 3.2m를 곱한 추정치를 사용한다. 둘 다 없으면 표시용 3.2m를 사용한다. 집계 대상 중 높이 후보 305,765개, 층수 추정 239,591개, 표시용 대체 150,395개다. 높이 후보도 공식 필드 문서나 현장 측량으로 확정한 값은 아니다. 셀 평균은 세 종류를 함께 계산한다.

Blender 색상은 셀 안의 높이 근거를 보여 준다. 푸른 회색은 높이 후보가 절반 이상, 베이지색은 높이 후보가 절반 미만이고 전부 결측은 아닌 셀, 갈색은 모두 표시용 대체 높이인 셀이다. QGIS 레이어 필드는 `district`, `buildings`, `mean_m`, `unknown`, `estimated`, `reported`, `district_parts`다. 마지막 속성은 각 구의 원본 건물 건수를 표시한다. QGIS는 격자를 단색으로 표시하며 속성 테이블에서 수치를 확인할 수 있다.

## 재생성과 검증

`aggregate_seoul.py`는 QGIS Python으로 원본 SHP를 읽어 압축 집계를 생성한다. 원본 경로와 출력 경로를 인자로 받는다. `build_seoul_overview.py`는 `blender -b --python build_seoul_overview.py`처럼 백그라운드 모드에서만 실행해 집계에서 모델을 만든다. 열린 작업 장면을 바꾸지 않도록 일반 Blender 창에서는 실행을 거부한다. 기존 모델을 덮어쓰므로 재생성 전 별도 폴더에 사본을 준비한다. `export_qgis.py`는 같은 집계로 GeoPackage와 프로젝트를 만들며 기존 GeoPackage 덮어쓰기를 거부한다.

검증: 집계와 GeoPackage의 123,626개 셀·695,751개 건물·25개 구 및 높이 분류별 수량이 일치했다. QGIS Python으로 프로젝트를 다시 열어 유효 레이어, EPSG:5186과 셀 수를 확인했다. Blender MCP에서 25개 구 메시의 셀·건물 수, 유한 좌표, 카메라 표시와 저장 상태를 확인했다. 정확한 개별 건물 모델이나 지리 정합의 검증은 아니다.
