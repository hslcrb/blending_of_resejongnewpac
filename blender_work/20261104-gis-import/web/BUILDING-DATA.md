# 건물 메타데이터 원본 타일

사용자가 제공한 `AL_D010_11_20261009.shp`와 DBF를 QGIS/GDAL로 CP949 디코딩해, 원본 695,753건의 FID·윤곽·A0~A28 필드를 1km EPSG:5186 타일 664개에 보존한다. `v5/public/area/buildings/manifest.json`은 타일과 건수를 기록하고, 각 gzip 타일은 중심점 기준으로 한 번만 저장한다. 경계를 가로지르는 건물을 찾을 때는 인접 타일도 확인하며 FID로 중복을 제거한다. 좌표 이상치 2건도 원본 타일과 전체 목록에 남긴다. 값이 없는 필드는 원본 그대로 보존한다.

`export_buildings.py`는 입력을 읽고 공간 타일을 작성한다. 좌표는 타일 원점에서 0.1m 단위 정수로 저장하며 멀티폴리곤과 내부 링을 유지한다. `export_building_points.py`는 695,753개 중심점을 웹 투사용 바이너리로 별도 생성한다. 표시용 높이는 A16 양수 후보를 쓰고 그 외에는 3m를 사용한다. 실제 원본 값은 타일에서 별도로 보여준다.

필드명은 한국교통연구원 [국가교통DB 보고서 표 5-15](https://www.ktdb.go.kr/DATA/pblcte/20250805093928585.pdf)를 참고했다. 로컬 파일이 해당 명세와 정확히 같은 버전인지는 확인되지 않았다. A4 법정동명과 A5 지번을 합친 것은 **지번 주소**이며 도로명 주소가 아니다. 정보는 원본의 시점·누락을 따르고 현재 건축물 현황을 보증하지 않는다. 사용자 파일의 배포 출처·이용 조건은 미확인이다.

`validate_buildings.py <원본.shp>`로 전체 고유 FID, 각 행의 29개 필드, 바이너리 점의 좌표 대응 및 원본 속성 표본 30개를 확인한다. 이번 실행에서 695,753건, 누락 0, 고유 FID 695,753개, 점 695,753개를 확인했다. 최대 타일 압축 크기는 434,444바이트이며 개별 파일 기준 Cloudflare Pages 한도 25MiB보다 작다.

`export_building_search.py`는 같은 타일에서 주소·건물명 검색용 25개 구역 색인을 생성한다. `validate_search.py`는 모든 색인 FID·타일·주소·건물명이 원본 타일과 일치하는지 확인하며, 이번 실행에서 695,753건이 일치했다. 웹에서 검색은 사용자가 요청할 때만 구역 색인을 가져오며, 결과가 200건에 도달하면 구체적인 검색어를 요청한다.
