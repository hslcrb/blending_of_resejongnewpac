# 세종문화회관 GIS 모델 작업 기록

## 파일과 범위

`sejong_surroundings_gis_work.blend`는 별도 세종 모델 프로젝트의 `public/model/sejong_surroundings_work.blend`를 이 저장소에 복사해 수정한 파일이다. 복사 전 원본 SHA-256은 `fc465f10280f7a5c93201c6b3afbc0fe59eca398449b9222531699aa89faaf2d`이며, 첫 커밋 `145dceb`에 원본과 같은 사본이 있다. 원본 프로젝트는 수정하지 않았다. Blender 5.2.3 및 Blender MCP에서 열고 저장했다.

`west-buildings.geojson`은 사용자가 보유한 `AL_D010_11_20261009.shp`에서 회관 서쪽 주변에 추출한 28개 건물 윤곽이다. 원본은 EPSG:5186, 단위 미터다. 원본의 출처 및 이용 조건은 아직 확인하지 못했다. 파일에는 위치와 높이 작업에 필요한 속성만 남겼다. `sejong-parcel-5186.geojson`은 속성을 제거한 세종로 81-3 건물 폴리곤 네 개다. QGIS에서 직접 열 수 있다.

## 배치와 한계

블렌더의 `GIS - western building context (provisional)` 컬렉션에 해당 윤곽을 압출해 주변 매스 28개와 지면 연장부를 추가했다. 원본의 A16 값이 양수면 이를 높이 후보로 사용했고, 그렇지 않으면 A26 값에 층당 3.2m를 곱했다. 필드 정의와 실제 높이는 확인되지 않아 모두 추정 매스다. 10㎡ 미만의 작은 폴리곤과 층수·높이가 없는 폴리곤은 제외했다. 기존 회관과 가까운 부분의 충돌을 줄이려고 서쪽으로 범위를 제한했으며, 주변 전체를 완성한 것은 아니다.

회관 지번 81-3의 폴리곤 범위와 기존 모델의 축·대략적인 외곽을 맞춰 `Blender X = EPSG 북거 - 552531`, `Blender Y = 197897 - EPSG 동거`로 변환했다. 사진 추정 모델을 기준으로 한 임시 정합이며 측량이나 실제 오차 검증이 아니다. 회관의 네 폴리곤은 숨겨진 `GIS - Sejong footprint reference (hidden)` 컬렉션에 따로 저장했다. 이 컬렉션을 켜면 회관 위쪽에서 주황색 윤곽이 표시된다. 비교를 위해 윤곽을 z=50m로 띄운 것이며 실제 높이를 나타내지 않는다. 렌더에는 포함되지 않는다. 기존 회관 건물 자체는 재모델링하지 않았다.

`build_west_context.py`는 첫 커밋의 사본에서 실행할 수 있는 재생성 스크립트다. 같은 컬렉션이 이미 있으면 중복 생성을 거부한다. GIS 원본이나 기존 모델을 덮어쓰지 않는다.

## 확인

- 28개 매스의 유한 좌표, 닫힌 메시와 위를 향한 지붕 법선을 Blender에서 확인했다. GIS 폴리곤은 유효하며 서로 0.01㎡를 초과해 겹치지 않는다.
- 기존 두 식재 컬렉션의 메시 경계 상자와 신규 건물 간 겹침을 검사했고 후보는 0개였다. 이 검사는 전체 장면의 충돌이나 실측 정합을 보증하지 않는다.
- Blender MCP의 위쪽·사선 화면에서 건물과 지면을 확인했다. GIS 입력의 건물 높이와 축 정합은 추가 확인이 필요하다.
- QGIS는 실행 중이었고 컴퓨터 사용 도구로 빈 프로젝트와 레이어 목록을 확인했다. 화면 캡처는 두 번 시간 초과되어 QGIS 화면의 시각적 확인은 하지 못했다.

2026-11-04 추가 검토: GIS 네 폴리곤의 외곽과 기존 모델은 대략 부합하나 내부의 차이도 확인됐다. 지붕 투영과 GIS 건축물 윤곽은 같은 측정 대상이 아니므로 이 차이만으로 회관을 이동하거나 형태를 덮어쓰지 않았다. 비교 윤곽만 더 잘 보이도록 보강했다.

## 동·남쪽 추가 검토

남쪽은 기존 표시 메시의 경계 상자와 충돌하지 않는 네 개 폴리곤을 골라 `GIS - southern building context (provisional)` 컬렉션에 압출했다. 1개는 A16 높이 후보, 3개는 A26 층수 × 3.2m를 사용한 추정치다. 소형 객체와 현장 실측까지 충돌을 확인한 것은 아니다. `south-buildings-5186.geojson`과 `build_south_context.py`에 입력과 재생성 절차를 보존했다.

동쪽의 네 GIS 후보는 현재 장면의 차도·보도와 크게 어긋나 기존 건물이나 길을 임의로 옮기지 않았다. `GIS - eastern footprints comparison (hidden)`을 켜면 주황색 비교 윤곽이 나타난다. 잘 보이도록 z=130m로 띄워 표시하므로 실제 높이가 아니며 렌더에 포함되지 않는다. `east-reference-5186.geojson`과 `build_east_reference.py`가 관련 자료다.
