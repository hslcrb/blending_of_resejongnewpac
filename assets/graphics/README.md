# 전면 화면·현수막 그래픽

세 SVG는 프로젝트용으로 직접 작성한 가상의 그래픽입니다. 첨부 사진은 화면의 위치·비례와 현수막의 색상 분위기 참고에만 사용했으며 사진, 공연 포스터, 타인의 로고 또는 일정을 추출하거나 포함하지 않았습니다. 실제 공연명, 날짜, 가격 또는 예매 정보가 아닙니다.

- `annex-screen.svg`: 1440×960, 3:2 화면용. 짙은 청록 바탕과 추상적인 무대 빛.
- `annex-banner.svg`: 3724×140, 26.6:1의 긴 전면 현수막. 분홍색 바탕과 큰 한글 문구.
- `annex-screen.png`: 위 화면 SVG를 1440×960 RGB로 렌더링한 Blender 이미지 텍스처.
- `annex-banner.png`: 위 현수막 SVG를 3724×140 RGB로 렌더링한 Blender 이미지 텍스처.
- `bridge-banner.svg`: 1440×360, 4:1 가로 행사 배너. 붉은 무대와 원형 조명을 직접 그린 가상의 그래픽.
- `bridge-banner.png`: 위 배너 SVG를 1440×360 RGB로 렌더링한 Blender 이미지 텍스처.

PNG는 각 SVG를 Chrome Headless에서 직접 열어 `--force-device-scale-factor=1`로 설정하고 원본 SVG와 같은 `--window-size`(화면 1440,960 / 현수막 3724,140 / 연결 배너 1440,360)에서 스크린샷으로 생성했습니다. 외부 사진 픽셀은 사용하지 않았습니다. PNG의 픽셀 크기와 렌더링 결과를 확인했습니다.
