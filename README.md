# 세종문화회관 건축 둘러보기

제공된 사진과 대극장 종단면 도면을 바탕으로 Blender에서 제작한 세종문화회관 외관 모델과 React 3D 뷰어입니다. 종단면의 전면·후면 기준선 간 거리 112.5m와 객석·무대 지붕 높이를 매스 배치에 참고했습니다. 정면 전체 폭과 도면에 나타나지 않은 세부는 사진의 비례에 따른 추정이며, 부조와 가려진 부분은 해석을 포함합니다. 정밀 실측 모델은 아닙니다.

도면의 지면 기준으로 객석 지붕 +35.060m, 무대 파라펫 +45.045m를 매스에 참고했습니다. 녹청 지붕의 마루 높이 +37.2m와 길이, 정면 전체 폭은 사진과 배치도에 근거한 추정입니다. 변환된 DWG의 일부 객체 이름에 경고가 있어 수치는 원본 도면과 교차 확인이 필요합니다. 112.5m는 기준선 사이의 길이이며 전체 외피 길이와 같다고 단정하지 않습니다.

## 실행

```sh
npm ci
npm run dev
```

`npm run build`는 Cloudflare Pages에 배포할 `dist` 디렉터리를 만듭니다. `main` 브랜치의 변경은 GitHub에 연결된 Cloudflare Pages에서 빌드합니다.

현재 Blender 작업본은 수목과 서울 하늘을 포함한 `blender_work/20261104-live-sky/blender_work/20261104/sejong_trees_connected_20261104.blend`입니다. 이전 작업본과 `public/model/`의 원본들은 보존했습니다. Windows에서 `open-seoul-sky.cmd`를 실행하면 이 사본과 실시간 하늘이 함께 시작됩니다. 23개 원본에 대응하는 하늘 사본과 실행 방법은 `docs/blender-weather-sky-20261104.md`에 기록했습니다. 웹은 `public/model/streaming-manifest.json`의 기본 외형을 먼저 불러오고, 거리와 화면 크기에 맞춰 정원·실내·주변 상세 GLB를 추가로 받습니다. 반복되는 수목 형상은 공유 버퍼 3개로 재사용합니다. `?environment=legacy`는 이전 단일 모델을 유지합니다.

항공사진을 참고해 별관 지붕의 앞뒤 길이를 본관의 약 50%로 늘리고 뒤 정원에 굽은 화단·벽돌 보행 공간과 수목을 보강했습니다. 이 비례와 위치는 사진에 따른 근사이며 실측값이 아닙니다. `scripts/build_sejong.py`는 이전 모델을 재생성하므로 현재 MCP 수정본을 덮어쓰는 용도로 사용하지 마세요. 부조·화면·현수막과 새 포장·석재 무늬는 직접 제작했으며 사진에서 잘라 쓰지 않았습니다.

사진 원본과 요청 기록은 [제작 브리프](docs/brief.md)와 [요청 원문](docs/references/user-requests-verbatim.md)에, 답사 149장 검토와 수작업 상세는 [11월 3일 기록](docs/sitevisit-mcp-20261103.md)에 정리했습니다. [항공 비례와 웹 연결](docs/sitevisit-aerial-web-20261103.md), [GLB 검증](docs/sitevisit-review/20261103-glb-verification.md), [웹 공간 로딩](docs/sitevisit-lazy-loading-20261103.md)에 이번 변경의 구현·검증 범위를 기록했습니다. 걷기 모드의 로비와 가려진 실내는 사진으로 완전히 검증된 복원이 아니라 해석을 포함합니다.

## 서울 시각과 기상 관측

웹 하늘은 서울 시각·날짜를 이용한 [NOAA 태양 위치 근사식](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)으로 1분마다 바뀐다. 구름 밀도는 [NOAA 항공기상 API](https://aviationweather.gov/data/api/)의 김포공항(RKSS) 최신 관측 범주를 이용하며, 공항과 광화문의 위치가 다르므로 현장 기상과 일치한다고 주장하지 않는다. 관측 시각을 화면에 표시하고, 2시간보다 오래된 관측이나 요청 실패는 알 수 없는 상태로 처리해 임의 구름 사용을 밝힌다.

NOAA API는 브라우저 CORS를 지원하지 않아 Cloudflare Pages Function `/api/weather`가 단일 공항 관측을 가져온다. 10분 캐시로 요청을 줄이고 오래된 응답은 제공하지 않는다. Vite 개발 서버에는 Pages Function이 없으므로 로컬 화면은 기상 실패 대체 상태가 정상이다. 2026-11-04 운영 경로에서 실제 관측 시각과 응답을 확인했다. 과거 프로젝트의 Blender 파일은 `blender_work/20261104-gis-import/sky/README.md`에 기록된 24시간 키프레임과 수동 실행 스크립트를 보존한다.

## 세종·서울·다른 지역 둘러보기

광화문 주변과 서울 전역을 한 장면에서 전환한다. 파빌리온·정원·걷기는 기존 상세 모형을 유지한다. 서울 건물은 GIS 50m 격자 평균이며 개별 건물 형태가 아니다. 돋보기는 선택 위치의 건물 후보와 지번·원본 29개 필드를 보여 준다. 전시천리안은 695,753건의 건물 위치를 투사하며, 겹칠 때에는 일부 요약 레이블과 전체 검색·지역별 목록으로 정보를 확인한다. 좌표 이상치 2건은 서울 범위 밖이다.

지면지도는 OpenStreetMap, 위성지도는 EOX Sentinel-2 cloudless 2016 합성 영상이다. 위성은 10m급으로 오래된 자료이며 현재 항공사진이 아니다. 지도 출처는 화면 안에 표시한다. 문화·집회 건물 후보는 사용자 제공 전국 건물 변경분의 일부이며, 전국 전체 시설이나 현재 운영 여부를 확인한 목록이 아니다. 후보 위치는 건물 폴리곤 내부 대표점이다. 자료·정확도·출처는 `docs/20261104-overview-gis.md`, `docs/national-cultural-changes.md`, `docs/20261104-basemap-tiles.md`에 기록했다.

### 리뉴얼 사이트 내장 경로

`/explore/?embed=1`은 같은 3D 서비스와 전국 후보 목록을 유지하면서 중복 사이트 머리글·소개·바닥글만 숨긴다. 리뉴얼 사이트에서 iframe의 제목과 전체 화면 권한을 제공하고, 직접 열기 링크도 둔다. 사용자 조작·데이터 요청은 이 서비스의 원본 URL을 사용한다.

내장 모드에서는 `sejong3d:height` 버전 1 메시지로 콘텐츠 높이를 리뉴얼 운영 출처에 알린다. 부모는 메시지 출처·발신 프레임·정수 높이 범위를 검증한다. 개발용 로컬 출처도 별도 허용하며 사용자 데이터는 전송하지 않는다.

## 자동 배포 운영

두 사이트는 각각 Cloudflare Pages의 Git 연동을 사용하며 `main` 커밋이 운영 배포를 시작한다. 이번 작업 브랜치의 미리보기(`feat/20261104-*`, `fix/20261104-*`, `docs/20261104-*`, `chore/20261104-*`, `test/20261104-*`)만 제외하고 다른 브랜치의 기존 미리보기는 유지한다. GitHub Actions는 추가하지 않았다. 푸시와 실제 운영 배포 성공은 구분해 확인한다.
